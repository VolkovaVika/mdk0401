# Практическая работа №4 — Авторизация (desktop)

**Выполнила:** Волкова Виктория

## Описание
Небольшое настольное приложение на Python с графическим интерфейсом Tkinter. Пользователь вводит логин и пароль. Приложение проверяет данные, позволяет показать пароль и закрывается после трёх неудачных попыток.

## Требования
- Python 3.10 или новее
- Tkinter (обычно входит в стандартную поставку Python)

## Запуск
1. Установите Python с официального сайта: https://www.python.org/
2. Откройте папку проекта в VS Code.
3. Запустите в терминале:

```bash
python authorize.py
```

## Тестовые данные
- Логин `admin`, пароль `1234`
- Логин `user`, пароль `qwerty`

Пароли в словаре хранятся в виде SHA-256 хешей. Данные для входа предназначены только для учебной демонстрации.
